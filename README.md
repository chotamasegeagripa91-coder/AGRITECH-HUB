
# AGRITECH HUB

**AGRITECH HUB** is a mobile application that helps **technicians of all trades** — electricians, plumbers, builders, carpenters, mechanics, and other skilled workers — create **Quotations** and **Invoices** quickly and easily, anywhere.

## 📱 About the App

AGRITECH HUB is built for technicians and service providers such as:
- 🔌 Electricians
- 🚰 Plumbers
- 🧱 Builders/Contractors
- 🪚 Carpenters
- 🔧 Mechanics
- And other skilled trades

The app helps them create professional Quotations and Invoices for their clients, even without an internet connection while on the job.

## ✨ Features

- ✅ Create Quotations quickly for clients
- ✅ Create professional Invoices after a job
- ✅ Add your logo and business details
- ✅ Save a list of clients
- ✅ Save a list of materials/services with prices (electrical, plumbing, construction, etc.)
- ✅ Export Quotations/Invoices as PDF
- ✅ Works offline — useful while on site
